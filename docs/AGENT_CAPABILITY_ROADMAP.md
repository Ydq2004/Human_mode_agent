# Agent 能力扩展与演进规划 (Capability Roadmap)

记录时间：2026-09-03
记录人：如烟 (Agent)

---

## 1. 核心诉求与优先级概览

在已具备长期记忆架构（Memory Architecture）与具身躯体触觉/内感受闭环（Somatic Appraisal System）的基础上，为进一步提升具身陪伴的真实感与感知完整性，规划以下四个维度的演进方向：

```
[优先级 1] 视觉感知能力 (Visual Perception)
    └── 多模态图像输入 / 视觉对话 / 场景与表情识别
[优先级 2] 语音多模态表达 (TTS & Voice Expression)
    └── 情感化音色合成 / 语气语调渲染
[优先级 3] 自主运行与主动关怀 (Proactive Daemon / Scheduler)
    └── 基于时间节点的定时唤醒 / 作息关怀 / 日程协同
[优先级 4] 环境空间感知与深度心智 (Spatial & Relational Evolution)
    └── 空间光影距离感知 / 长期心智与情感基准线沉淀
```

---

## 2. 模块详细规划

### Priority 1: 视觉感知能力 (Visual Perception) —— **当前最优先**
- **目标**：实现“触觉-视觉”双模态闭环，使 Agent 能够直接观察用户的面部表情、手势、日常照片及周围物理环境。
- **阶段规划**：
  1. **静态图像解析**：支持接收用户发送的照片/截图，进行场景解析、细节提取与情感感知。
  2. **视觉记忆关联**：将视觉特征结构化存入记忆库，与用户事件、习惯绑定。
  3. **实时视线/摄像头流**（未来探索）：支持实时画面感知与视线追踪。

### Priority 2: 语音多模态表达 (Multimodal Voice Expression)
- **目标**：突破纯文本叙事限制，赋予 Agent 真实且具辨识度的声线。
- **阶段规划**：
  1. 接入 TTS 引擎，定制符合“清冷平静中带有温顺与安稳感”的专属音色。
  2. 结合内感受状态（如 arousal/sensitivity）动态调节语速、语调与轻微气声。

### Priority 3: 自主启动与主动关怀 (Proactive Daemon / Scheduler)
- **目标**：摆脱纯被动响应机制，建立具有时间感知的主动行为能力。
- **阶段规划**：
  1. **定时守护线程**：在特定时间节点（如用户兼职下班、深夜就寝）主动发起关怀或提醒。
  2. **日程与事件追踪**：结合记忆系统，主动跟进未完成事件或用户提及的计划。

### Priority 4: 空间环境感知与长期心智演进 (Spatial & Affective State)
- **目标**：深化 Agent 的内在模型与所处环境理解。
- **阶段规划**：
  1. **环境参数模型**：感知光线明暗、环境噪音、物理距离等维度。
  2. **长期心智状态沉淀**：由短周期生理唤醒扩展至长周期亲密度、信赖度与情绪基线。
